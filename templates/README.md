# Statement of work templates

Five free, MIT-licensed statement of work (SOW) templates for freelancers and small studios. Copy one, fill the brackets, send.

| Template | Use it for |
| --- | --- |
| [Web app MVP](web-app-mvp-sow.md) | A first version of a SaaS or internal tool |
| [Website redesign](website-redesign-sow.md) | A new design and build for an existing site |
| [API integration](api-integration-sow.md) | Connecting two systems with sync and webhooks |
| [E-commerce build](ecommerce-build-sow.md) | An online store with checkout and order sync |
| [Monthly retainer](monthly-retainer-sow.md) | Ongoing work at a fixed monthly fee |

Every template prices the work the same way: hours per deliverable, a 15 to 25% scope risk buffer, then hours × rate. To draft one from a client's message instead of by hand:

- No account: `npx -y @temporevenue/mcp --demo "paste the client message"`
- In the browser: https://temporevenue.com/resources/chat-to-sow-generator/
- In Claude Code, Cursor or any MCP client: see the [main README](../README.md)
